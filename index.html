CSS Box Model — როგორ ითვლის ბრაუზერი ზომებს?

ვებგვერდზე ყველა ელემენტი, მართკუთხა „ყუთია“, და სწორედ Box Model განსაზღვრავს, რამდენ ადგილს დაიკავებს ის ეკრანზე. ამ მექანიზმის გაგების გარეშე ელემენტები მოულოდნელად „იბერება“ და განლაგება ირღვევა.

დიდი დუელი: Content-Box vs Border-Box

ორივე ბარათს ერთნაირი პარამეტრები აქვს: width: 300px, padding: 20px, border: 5px solid. მაგრამ შეხედე, რა განსხვავებული შედეგია!

ბარათი A — content-box

box-sizing: content-box;

ეს ბრაუზერის დეფოლტ ქცევაა. width მხოლოდ კონტენტს ეხება, padding და border კი ზემოდან ემატება.

რეალური სიგანე: 350px
300 + (20 × 2) + (5 × 2) = 350

საბოლოო ზომა = Width + Padding + Border

ბარათი B — border-box

box-sizing: border-box;

აქ width მოიცავს ყველაფერს: padding და border „ჩაიფუთება“ მითითებული სიგანის შიგნით.

რეალური სიგანე: 300px
padding და border უკვე ამ 300-შია

საბოლოო ზომა = Width

A: 350px
B: 300px

ოქროს წესი (Best Practice)

თითქმის ყველა პროექტი ამ რამდენიმე ხაზით იწყება:

*, *::before, *::after {
  box-sizing: border-box;
}

ეს წესი ყველა ელემენტზე ზომების გამოთვლას პროგნოზირებადს ხდის: რაც სიგანედ დაწერე, ზუსტად იმდენს დაიკავებს — padding-ისა და border-ის დამატებისას ხელით გადათვლა აღარ გჭირდება.
